# Research Projects

Project websites hosted with GitHub Pages.

- [CarryOn](https://vincent2311.github.io/Projects/CarryOn/) — A Dual-Loop Harness for Personalized and Reliable Robot Assistance.

## Structure

Each project has its own directory. `CarryOn/` contains its HTML, JavaScript, CSS, and media. The root `index.html` lists available projects.

## Deployment

GitHub Pages serves the root of the `gh-pages` branch. The `main` branch retains the same source. No build dependencies are required.

Add future projects in separate directories and link them from the root `index.html`. Preserve existing projects when publishing updates.
