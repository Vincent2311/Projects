# CarryOn

A Dual-Loop Harness for Personalized and Reliable Robot Assistance.

Website: https://vincent2311.github.io/Projects/

## Website files

This repository contains the static project website and the media it uses.
- `index.html`: page content and results.
- `app.js`: interactive figures and video comparisons.
- `style.css`: responsive layout.
- `assets/`: figures, video clips, and posters.

## Deployment

GitHub Pages serves the root of the `gh-pages` branch. The `main` branch retains the same site source. No build dependencies are required.

For local preview, serve the repository with a static HTTP server, such as `python -m http.server 8000`.
